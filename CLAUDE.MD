Основные сущности

ProductionTask — задача. ParentRowNumber = null → корневая. IsSplitTask = true → родитель разделённой задачи. Дочерние задачи имеют ParentRowNumber = id родителя и IsSplitTask = true.
WorkInterval — интервал работы. StartTime / EndTime (null = открыт).
JobStatus: Assigned (Назначена), InProgress (Начал), Paused (Пауза), Completed (Готово).
🧩 Разделение задач (сплит)

Админ делит корневую задачу на части (дочерние) для разных сотрудников.
Родительская остаётся IsSplitTask=true, видна только в таблице.
Дочерние получают своего сотрудника, тип работы, часы. Сотрудник видит свою часть в календаре и таблице.
Родительская считается выполненной, когда все дочерние Completed.
Статус родителя:

Assigned — никто не начинал.
InProgress — хотя бы одна дочерняя начата/на паузе.
Completed — все дочерние завершены.
🕒 Рабочее время

Пн–Пт: 10:00–14:00, 15:00–19:00. Обед 14:00–15:00 — задачи не планируются.
Сб, Вс — выходные.
WorkHoursCalculator проверяет IsWorkingHour, добавляет часы, считает разницу.
📅 Календарь (WeekCalendar)

Показывает только задачи выбранного сотрудника (включая дочерние, где он назначен). Родительские не отображаются.
Две цветные полосы для каждого дня:

План (ScheduledSlot) — задачи, отсортированные по дедлайну, уложенные в рабочее время.
Реальное выполнение (WorkInterval) — фактические отрезки работы (с учётом обеда, многослойность).
Дедлайны отмечены цветными маркерами (красный — риск/просрочка, зелёный — завершена).
✅ Жизненный цикл задачи (частной или дочерней)

Начать → создаётся открытый интервал (EndTime = null), статус → InProgress.
Пауза → закрывается текущий интервал, статус → Paused.
Продолжить → создаётся новый открытый интервал, статус → InProgress.
Готово → закрывается интервал, считается фактическое время (ActualHours = сумма длительностей).

Если это дочерняя задача → проверяется, не завершились ли все дети, и тогда родитель становится Completed.
Экономия часов (EstimateHours - ActualHours) добавляется в статистику сотрудника (EmployeeStats).
📋 Таблица задач

Корневые задачи с пагинацией.
Админ видит всё, может создавать, редактировать, удалять, разделять.
Сотрудник видит только свои незавершённые задачи (включая дочерние). Может менять статус и комментировать.
Подсветка (лампочка):

Для сотрудника — задачи, где он участвует (назначен или есть незавершённая дочерняя часть).
Для админа — задачи выбранного сотрудника из выпадающего списка.
🔔 Уведомления (SignalR)

NewTask — при создании задачи отправляется её исполнителю.
TaskUpdated — при изменении задачи (поля, дедлайн) уведомляются старый и новый исполнитель.
TaskDeleted — удаление.
TaskStatusChanged / TaskProgressChanged — синхронизация статусов между календарём и таблицей.
📂 Открытие файлов

POST /api/files/open → передаётся путь вида Клиенты/папка/файл.cdr.
macOS: open "smb://MINIMARKER/Клиенты/...".
Windows: Process.Start с UseShellExecute = true на UNC \\MINIMARKER\Клиенты\....
🛠 Панель отладки (DebugPanel)

Подмена системного времени (мок).
Принудительное создание/закрытие интервалов (для тестирования).
Сброс всей БД.
🧠 Важные связи

Календарь и таблица синхронны через API и SignalR — изменение статуса в любом месте сразу отражается везде.
Активные задачи (список под календарём) — задачи со статусом не Completed, отфильтрованные по сотруднику.
Выполненные задачи — задачи Completed с расчётом периода выполнения и разницы часов.
