ProductionPlanner — локальный агент для открытия файлов с Windows

1. Распакуйте ZIP в любую папку.
2. Запустите install.bat (двойной клик).
3. После установки открывайте файлы из приложения как обычно.

Агент слушает только http://127.0.0.1:17888 на вашем ПК.
Открывает файлы только из \\MINIMARKER\Клиенты\...

Удаление: запустите uninstall.ps1 из папки установки
(%LOCALAPPDATA%\ProductionPlanner\FileOpener) или удалите задачу
«ProductionPlanner File Opener» в Планировщике заданий.
