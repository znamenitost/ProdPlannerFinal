## ProductionPlanner Print Agent

Локальный агент печати этикеток (Windows 7 SP1 / 10 / 11).

## Макет этикетки (термо 75×120 мм)

Бумага выходит вдоль длинной стороны (120 мм). Текст — вдоль этой же оси.

```
←—————— 75 мм ——————→
     ← 30 → ← 30 →
┌─────┬──────┬──────┬─────┐
│     │      │      │     │
│поле │Комп. │Номер │поле │  120 мм
│     │вдоль │вдоль │     │  (направление выхода)
│     │120мм │120мм │     │
│     │      │      │     │
└─────┴──────┴──────┴─────┘
```

- Слева **30×120**: название компании (`Клиенты/И/Интан` → `Интан`), вдоль длинной оси.
- Справа **30×120**: номер заказа (код получения), вдоль длинной оси, параллельно названию.

## Требования

- .NET Framework 4.8
- Интернет до `https://app-mainstream.ru`
- Принтер установлен в Windows на этом ПК
- Размер наклейки в драйвере: **75 × 120 мм**

## Установка

1. Скачайте zip с сайта (меню → агент печати) **или** соберите: `dotnet build -c Release`.
2. **Распакуйте весь ZIP в папку** (рядом с `.exe` должны лежать все `.dll`).  
   Не запускайте exe прямо из окна архива.
3. Нужен .NET Framework 4.8.
4. Запустите `ProductionPlanner.PrintAgent.exe` — откроется окно настроек и значок в трее.
5. Адрес сайта (например `https://app-mainstream.ru`), принтер → **Сохранить** → **Подключить**.

Токен должен совпадать с `PrintAgent:AccessToken` на сервере (в сборке уже прописан дефолт).

Если окно не появляется: снимите процесс в диспетчере задач и запустите снова. При ошибке теперь показывается MessageBox с текстом.
