# ProductionPlanner Print Agent

Локальный агент печати этикеток (Windows 7 SP1 / 10 / 11).

## Макет этикетки (A4, верх листа)

```
┌──────────────────────────────────┬───────────┬────────┐
│  АРЕТА   (~2 см, последняя папка)│ получение │        │
│  vizitki.cdr → vizitki (файл)    │    А42    │  [QR]  │
└──────────────────────────────────┴───────────┴────────┘
 · · · · · · · · · · · · · · отрыв · · · · · · · · · · ·
```

QR ведёт на страницу этого заказа: `/t/{token}?c={код}`.
## Требования

- .NET Framework 4.8
- Интернет до `https://app-mainstream.ru`
- Принтер установлен в Windows на этом ПК

## Установка

1. Соберите: `dotnet build -c Release` в этой папке (на машине разработчика).
2. Скопируйте содержимое `bin/Release/net48/` на ПК с принтером.
3. Запустите `ProductionPlanner.PrintAgent.exe`.
4. Выберите принтер из списка, проверьте токен, включите «Запускать с Windows», **Сохранить**.
5. Нажмите **Подключить** (или агент подключится сам, если принтер уже выбран).

Токен должен совпадать с `PrintAgent:AccessToken` на сервере.
