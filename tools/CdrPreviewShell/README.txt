CDR Preview для Проводника Windows
==================================

Показывает встроенное превью файлов .cdr в панели предпросмотра
Проводника (.NET) и миниатюры в режимах «Крупные значки» / «Огромные значки»
(нативный C++ обработчик). CorelDRAW не нужен.

Требования:
- Windows 10 или 11 (64-bit)
- .NET Framework 4.8 (обычно уже есть в системе)

Установка:
1. Распакуйте ZIP в любую папку.
2. Запустите install.bat от имени администратора (ПКМ → Запуск от имени администратора).
3. В Проводнике: Вид → Показать → Панель предпросмотра (для бокового превью).
   Для миниатюр в самой папке: Вид → Крупные значки или Огромные значки.
4. Выберите файл .cdr — справа появится превью, в папке — миниатюра.

Обновление (если «файл занят»):
1. uninstall.bat от администратора.
2. stop-handlers.bat от администратора.
3. Замените файлы или распакуйте ZIP в новую папку.
4. install.bat от администратора.

Проще: распакуйте новую версию в другую папку, uninstall из старой, install из новой.

Если миниатюры не появились:
- install.bat заново от администратора (очищает кэш миниатюр).
- diagnose.bat — InprocServer32 должен указывать на CdrThumbnailNative.dll (не mscoree.dll).
- test-com.bat — проверка COM-активации нативного обработчика.

Удаление:
- Запустите uninstall.bat от имени администратора.

Примечания:
- Работает с локальными дисками (C:\, D:\ и т.д.).
- Сетевые пути могут работать медленнее.
- Если CorelDRAW уже установлен, его превью может иметь приоритет.
