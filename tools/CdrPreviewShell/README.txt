CDR Preview для Проводника Windows
==================================

Показывает встроенное превью файлов .cdr в панели предпросмотра
Проводника. CorelDRAW не нужен.

Требования:
- Windows 10 или 11 (64-bit)
- .NET Framework 4.8 (обычно уже есть в системе)

Установка:
1. Распакуйте ZIP в любую папку.
2. Запустите install.bat от имени администратора (ПКМ → Запуск от имени администратора).
3. В Проводнике: Вид → Показать → Панель предпросмотра.
4. Выберите файл .cdr — справа появится превью.

Удаление:
- Запустите uninstall.bat от имени администратора.

Примечания:
- Работает с локальными дисками (C:\, D:\ и т.д.).
- Сетевые пути могут работать медленнее.
- Если CorelDRAW уже установлен, его превью может иметь приоритет.
